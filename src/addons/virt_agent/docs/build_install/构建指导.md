# 构建指导

> virt_agent 是 UBSE 的 add-on 插件，随 UBS Engine 主工程一起构建，无独立构建入口。
> 构建环境、依赖安装、出包流程与 UBSE 一致，本文仅说明 virt_agent 相关的构建要点。

## 1. 前置说明

- 仅支持在 openEuler 操作系统上构建，推荐 openEuler 24.03 LTS SP3/SP4，目标架构 aarch64；
- 构建环境准备（物理机/虚拟机/WSL/Docker）详见 [UBSE 构建指导 - 构建环境准备](../../../../../docs/build_install/构建指导.md#1-构建环境准备获取-openeuler-系统镜像)。

## 2. 拉取源码

```shell
git clone https://atomgit.com/openeuler/ubs-engine.git
cd ubs-engine
```

## 3. 构建

### 3.1 构建依赖

virt_agent 随主工程构建，**构建依赖与 UBSE 完全一致，无额外依赖**。依赖安装方式（spec BuildRequires 一键安装或源码编译）详见 [UBSE 构建指导 - 构建依赖](../../../../../docs/build_install/构建指导.md#31-构建依赖)。

virt_agent 代码中使用的第三方库如下，均由 UBSE 统一引入，无需单独安装：

| 库             | 在 virt_agent 中的用途                             |
| -------------- | -------------------------------------------------- |
| RapidJSON      | HAM 迁移北向报文、水位告警事件等 JSON 的解析与构建 |
| libboundscheck | 安全函数库（`virtagent` 目标链接）                 |

如需运行单元测试，另需安装 GTest/GMock（`yum install -y gtest gtest-devel gmock gmock-devel`），详见 [UBSE 构建指导 - 单元测试](../../../../../docs/build_install/构建指导.md#33-单元测试)。

> **注意**：`ubs-comm-devel >= 1.0.3-3` 目前仅合入 openEuler-24.03-LTS-Next 分支，SP3/SP4 正式镜像源通常只提供 1.0.0-x 版本——即使能安装，编译时也会因缺少新接口（如 `ubs_hcom_channel_set_trace_id`）报错。请按 [UBSE 构建指导 - 其他 openEuler 版本依赖安装说明](../../../../../docs/build_install/构建指导.md#312-其他-openeuler-版本依赖安装说明)从源码编译 ubs-comm 后再构建。

### 3.2 执行构建

随 UBSE 整体构建（推荐）：

```shell
# Release 构建（默认，UB 优化默认开启）
bash build.sh

# Debug 构建
bash build.sh -D

# Release + 调试信息（推荐用于问题定位）
bash build.sh -T RelWithDebInfo

# 限制并行编译任务数（内存受限环境）
bash build.sh -j 4

# 清理构建目录后重新构建
bash build.sh -c
```

与 virt_agent 相关的 CMake 目标：

| CMake 目标           | 产物                       | 说明                                                                                                                                                                                      |
| -------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `virtagent`          | `lib/libvirtagent.so`      | 插件主体（服务端，由 ubse 进程动态加载）                                                                                                                                                  |
| `ubs_virt_agent_sdk` | `lib/libubs-virt-agent.so` | 客户端 SDK 运行库：面向 C/Go/Python 调用方，经 UDS IPC 调用 ubse 进程中的 virt_agent 插件                                                                                                 |
| `strategy`           | `lib/libstrategy.so`       | 超分场景默认逃逸策略算法库：水位告警触发时计算内存借用/归还量（归还线 0.80、一次逃逸线 0.85、二次逃逸线 0.92），由 virt_agent 经 `escape.algorithm.dir` dlopen 加载，可替换为自定义策略库 |

整体构建完成后如仅需重新编译插件，可通过构建脚本单独构建目标（推荐）：

```shell
# 目标名见上表，如 virtagent；构建目录随构建类型变化
# Release: cmake-build-release，Debug: cmake-build-debug，RelWithDebInfo: cmake-build-relwithdebinfo
bash build.sh virtagent
```

也可在已配置的构建目录中直接构建：

```shell
cmake --build cmake-build-release --target virtagent
```

### 3.3 构建产物

构建产物位于 `cmake-build-<type>/` 下：

```text
cmake-build-<type>/
└── lib/
    ├── libvirtagent.so        # 插件主体
    ├── libubs-virt-agent.so*  # 客户端 SDK 运行库
    └── libstrategy.so         # 默认逃逸策略算法库
```

构建完成后可在构建机上进行产物自检（目标机运行依赖由 RPM 安装保证）：

```shell
# 1. 确认产物已生成（含软链指向）
ls -l cmake-build-release/lib/libvirtagent.so cmake-build-release/lib/libubs-virt-agent.so*

# 2. 检查动态库依赖可解析：无 "not found" 即依赖完整
ldd cmake-build-release/lib/libvirtagent.so | grep 'not found' || echo "依赖解析正常"
```

### 3.4 单元测试

virt_agent 单元测试位于 `test/UT/exclusive_executable/virt_agent/` 下，按 UBSE 统一方式构建运行：

```shell
# 运行全部 UT
bash build.sh ut

# 仅运行 virt_agent 模块 UT
bash build.sh ubse_virtagent_ut

# 运行指定用例（gtest 过滤，套件名如 TestDefaultStrategy）
bash build.sh ut -- --gtest_filter="TestDefaultStrategy.*"

# 生成覆盖率报告
bash build.sh ut -C
```

用例编写规范详见[单元测试开发指南](../test/单元测试开发指南.md)。

### 3.5 常见问题

| 现象                                                | 原因                                              | 处理                                                                                  |
| --------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------- |
| CMake 配置报找不到 RapidJSON                        | 缺少 `rapidjson-devel`                            | `sudo dnf install -y rapidjson-devel`                                                 |
| 编译过程被 OOM Killer 终止                          | 并行编译任务数过高                                | 使用 `bash build.sh -j 4` 降低并行度或扩容内存                                        |
| 编译报 `ubs_hcom_channel_set_trace_id` 等符号未声明 | `ubs-comm-devel` 版本过低（SP3/SP4 源仅 1.0.0-x） | 按 UBSE 构建指导 3.1.2 源码编译 `ubs-comm >= 1.0.3-3` 后重新构建（实测 1.0.3-4 可用） |

## 4. 形成 RPM 包

```shell
bash build.sh package
```

出包流程与 UBSE 一致，产物输出到项目顶层 `output/` 目录，详见 [UBSE 构建指导 - 形成rpm包](../../../../../docs/build_install/构建指导.md#4-形成rpm包)。

virt_agent 相关产物：

| RPM 包                                                       | 说明                                                                   |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| `ubs-engine-virtagent-<version>-<release>.aarch64.rpm`       | 主程序包（插件库、客户端 SDK 运行库、配置文件、默认策略库）            |
| `ubs-engine-virtagent-devel-<version>-<release>.aarch64.rpm` | 开发包（SDK 头文件与开发软链）                                         |
| `python3-ubs-engine-<version>-<release>.noarch.rpm`          | Python SDK 包（UBSE 共享，合并打包框架 SDK 与 virt_agent Python 接口） |

安装部署详见[部署说明](部署说明.md)。
