# 构建指导

> **支持环境**：本项目仅支持在 **openEuler** 操作系统上构建，推荐使用 openEuler 24.03 LTS SP3/SP4。
> 构建前请先确认操作系统为 openEuler（`cat /etc/openEuler-release`），并按系统版本选择下文对应的依赖安装说明。
> 其他发行版（如 Ubuntu、Debian）不在支持范围内，依赖无法通过系统包管理器获取，需自行解决，本项目不提供支持。

## 1 拉取源码

```shell
git clone https://atomgit.com/openeuler/ubs-engine.git
```

## 2 构建

### 2.1 构建依赖

项目依赖分为两类：

- **打包构建依赖**：记录在 spec 文件（[ubs-engine.spec](../../ubs-engine.spec)）BuildRequires 中，打包时通过 `dnf builddep -y ubs-engine.spec` 一键安装
- **开发与单元测试依赖**：在打包构建依赖基础上，另需 GTest/GMock 测试框架（`yum install -y gtest gtest-devel gmock gmock-devel`），仅 `bash build.sh ut` 开发/测试场景需要

由于当前依赖的ubs-comm-devel版本只发布在openEuler 24.03 LTS SP3/SP4，通过`cat /etc/openEuler-release`确认编译系统版本：

- 如果编译系统版本为`openEuler release 24.03 (LTS-SP3)/(LTS-SP4)`，参考[2.1.1 openEuler release 24.03 (LTS-SP3)/(LTS-SP4) 依赖安装说明](#211-openeuler-release-2403-lts-sp3lts-sp4-依赖安装说明)
- 如果是其他版本，参考[2.1.2 其他 openEuler 版本依赖安装说明](#212-其他-openeuler-版本依赖安装说明)

#### 2.1.1 openEuler release 24.03 (LTS-SP3)/(LTS-SP4) 依赖安装说明

| openEuler 版本 | ubs-comm-devel 版本要求 |
|----------------|------------------------|
| 24.03 LTS-SP3  | >= 1.0.0-27            |
| 24.03 LTS-SP4  | >= 1.0.1-7             |

安装前请先核对仓库中 `ubs-comm-devel` 版本满足上表要求（`dnf list ubs-comm-devel`）：

- **方式一：DNF一键安装**

    ```shell
    # 安装spec中指定的BuildRequires
    cd ubs_engine
    dnf builddep -y ubs-engine.spec
    ```

- **方式二：yum手动安装**

    ```shell
    yum install -y libboundscheck libxml2-devel numactl-libs openssl-devel rapidjson-devel patch libvirt-devel kernel-devel 'cpp-httplib-devel >= 0.40.0' 'ubs-comm-devel >= <对应SP版本要求>' ...
    ```

> 若仓库中版本不满足对应 SP 的版本要求，或找不到该包，跳转到 [2.1.2 其他 openEuler 版本依赖安装说明](#212-其他-openeuler-版本依赖安装说明)。

#### 2.1.2 其他 openEuler 版本依赖安装说明

> 注意：使用其他openEuler版本时,安装到的三方库依赖可能不存在或版本不满足要求，需从源码编译 ubs-comm。

执行以下命令安装依赖：

```shell
yum install -y libboundscheck libxml2-devel numactl-libs openssl-devel rapidjson-devel patch libvirt-devel cpp-httplib-devel kernel-devel
```

源码编译 ubs-comm-devel 和 ubs-comm-lib：

```shell
# 安装基础工具链和 rpm 构建工具
sudo dnf install -y git rpm-build rpmdevtools gcc gcc-c++ make
mkdir -p /tmp/src
# 下载 ubs-comm 源码
git clone -b openEuler-24.03-LTS-SP4 https://gitcode.com/src-openeuler/ubs-comm.git /tmp/src/ubs-comm
# 初始化 rpmbuild 目录结构
rpmdev-setuptree
# 复制 ubs-comm 源码中的 spec 文件到 rpmbuild 目录
cp /tmp/src/ubs-comm/ubs-comm.spec ~/rpmbuild/SPECS/
cp -rf /tmp/src/ubs-comm/ubs-comm-*.tar.gz ~/rpmbuild/SOURCES/
# 安装 ubs-comm.spec 中指定的 BuildRequires
sudo dnf builddep -y ~/rpmbuild/SPECS/ubs-comm.spec
# 构建 ubs-comm 包
rpmbuild -ba ~/rpmbuild/SPECS/ubs-comm.spec
# 安装构建得到的 rpm 包
# 架构为aarch64
sudo dnf install -y ~/rpmbuild/RPMS/aarch64/ubs-comm-lib-*.rpm
sudo dnf install -y ~/rpmbuild/RPMS/aarch64/ubs-comm-devel-*.rpm
# 架构为x86_64
sudo dnf install -y ~/rpmbuild/RPMS/x86_64/ubs-comm-lib-*.rpm
sudo dnf install -y ~/rpmbuild/RPMS/x86_64/ubs-comm-devel-*.rpm
```

### 2.2 执行构建

```shell
# 执行 Release 构建（没有调试信息，-O2 优化）
bash build.sh

# 执行 Debug 构建（附加调试信息）
bash build.sh -D

# 执行 RelWithDebInfo 构建（附加调试信息，-O2 优化）
bash build.sh -T RelWithDebInfo

# 执行 MinSizeRel 构建（没有调试信息，二进制文件最小构建，-Os 优化）
bash build.sh -T MinSizeRel
```

### 2.3 单元测试

支持 5 个独立的 UT 测试二进制：

| 二进制 | 测试范围 |
|--------|---------|
| `ubs-engine_ut` | 主项目单元测试 |
| `ubs-engine_ucache_plugin_ut` | ucache 插件测试 |
| `ubs-engine_rmrs_plugin_ut` | 内存池化插件测试 |
| `ubs-engine_virtagent_ut` | 虚拟化代理测试 |
| `ubs-engine_process_mem_ut` | processmem 插件测试 |

> **注意**：`ut` target 将编译和测试执行绑定为单一 ninja target，若某个测试失败将导致后续测试的编译/执行被中断。
> 建议优先使用 `--skip-run-tests` 分批操作。

```shell
# 编译并运行所有测试
bash build.sh ut

# 只编译不执行（推荐：先用此命令确保全部编译通过）
bash build.sh ut --skip-run-tests

# 编译单个测试二进制
bash build.sh ut --skip-run-tests -t ubs-engine_ut

# 运行部分用例
bash build.sh ut -- --gtest_filter="TestSuite.*"
```

## 3 形成rpm包

```shell
# 构建项目，并打包成 rpm 文件输出到项目顶层目录的 output/ 下。
bash build.sh package
```

产物如下：

```path
└── output                                                            # 打包输出文件目录
    ├── ubs-engine-<version>-<release>.aarch64.rpm                    # 主程序包
    ├── ubs-engine-client-libs-<version>-<release>.aarch64.rpm        # 客户端运行时库
    ├── ubs-engine-client-devel-<version>-<release>.aarch64.rpm       # 客户端开发包
    ├── python3-ubs-engine-<version>-<release>.aarch64.rpm            # Python API 包
    ├── ubs-engine-rmrs-<version>-<release>.aarch64.rpm               # 内存池化插件
    ├── ubs-engine-ucache-<version>-<release>.aarch64.rpm             # ucache 插件
    ├── ubs-engine-virtagent-<version>-<release>.aarch64.rpm          # 虚拟化代理插件
    ├── ubs-engine-processmem-<version>-<release>.aarch64.rpm         # processmem 插件
    └── ubs-engine-debuginfo-<version>-<release>.aarch64.rpm          # 调试信息
```

子包依赖关系详见 [部署说明中的依赖分组说明](./部署说明.md#11-依赖分组说明)。
